道の駅 森旅マップ 公開版

GitHub Pages でそのまま公開できます。

含まれる主なファイル
- index.html
- hotels.json（楽天トラベル取得済み宿泊施設データ）
- manifest.webmanifest
- icon-192.png
- icon-512.png
- sw.js（既存版）
- official_stations.json（既存版）

公開手順
1. GitHub の michinoeki-nature-map リポジトリを開く
2. ZIP 内のファイルをリポジトリ直下へアップロード
3. 既存ファイルは上書き
4. Commit changes
5. Settings → Pages → main / (root)
6. 公開URLを開いて再読み込み

この版では温泉施設機能は削除済みです。
最下部の切替は「鉄道駅」「宿泊施設」の2つです。
道の駅・宿泊施設は、現在表示している地図範囲とズームに応じて表示数を調整します。
